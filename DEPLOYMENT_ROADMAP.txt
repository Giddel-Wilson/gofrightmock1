┌──────────────────────────────────────────────────────────────────────────────┐
│ 📝 STEP-BY-STEP: RAILWAY DEPLOYMENT (RECOMMENDED)                           │
└──────────────────────────────────────────────────────────────────────────────┘

STEP 1: Create Railway Account
   → Visit: https://railway.app/
   → Sign up with GitHub (free)

STEP 2: Provision MySQL Database
   → Click "New Project"
   → Select "Provision MySQL"
   → Wait for deployment (2-3 minutes)

STEP 3: Get Database Credentials
   → Click on MySQL service
   → Go to "Variables" tab
   → Copy these values:
     • MYSQLHOST
     • MYSQLUSER  
     • MYSQLPASSWORD
     • MYSQLDATABASE

STEP 4: Update Your .env File
   → Open: /Users/maintenance/Documents/Cargo-Tracking-System-master/.env
   → Replace with:

   DB_SERVER=containers-us-west-xxx.railway.app
   DB_USER=root
   DB_PASS=your_railway_password
   DB_NAME=railway
   SERVER_PORT=8080
   SERVER_HOST=0.0.0.0
   APP_ENV=production

STEP 5: Import Database Schema
   → In terminal, run:
   
   mysql -h containers-us-west-xxx.railway.app \
         -u root \
         -p'your_password' \
         railway < database.sql

STEP 6: Deploy Application to Railway
   → Push code to GitHub
   → In Railway: "New Project" → "Deploy from GitHub"
   → Select your repository
   → Railway auto-detects PHP and deploys

STEP 7: Set Environment Variables in Railway
   → In Railway project settings
   → Add variables from your .env file
   → Railway will restart automatically

STEP 8: Test Your Deployment
   → Railway provides a URL like: gofreight.up.railway.app
   → Visit: https://gofreight.up.railway.app/home/home.php
   → Login and test all features

STEP 9 (Optional): Add Custom Domain
   → In Railway settings
   → Click "Add Domain"
   → Follow DNS instructions

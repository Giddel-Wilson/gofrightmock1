┌──────────────────────────────────────────────────────────────────────────────┐
│ 🔧 IMPORTING DATABASE TO CLOUD                                              │
└──────────────────────────────────────────────────────────────────────────────┘

FOR AIVEN (with SSL):
────────────────────
1. Download CA certificate from Aiven dashboard
2. Save as: ca-certificate.crt in project root
3. Run:
   mysql --host=your-host \
         --port=12345 \
         --user=avnadmin \
         --password=your_pass \
         --ssl-ca=ca-certificate.crt \
         defaultdb < database.sql

FOR FREESQLDATABASE (no SSL):
─────────────────────────────
mysql -h sql12.freesqldatabase.com \
      -u sql12xxxxx \
      -pyour_password \
      sql12xxxxx < database.sql

FOR RAILWAY (no SSL):
────────────────────
mysql -h containers-us-west-xxx.railway.app \
      -u root \
      -pyour_password \
      railway < database.sql

│ 🆘 TROUBLESHOOTING                                                           │
└──────────────────────────────────────────────────────────────────────────────┘

Database connection error:
  → Check .env values are correct
  → Test: php -r "include 'includes/db_connection.php'; echo 'OK';"

Login not working:
  → Verify database has admin/customer/driver accounts
  → Check: mysql -u root cargo -e "SELECT * FROM admin;"

Server not accessible:
  → Check server is running on port 8000
  → Visit: http://localhost:8000/home/home.php

Port already in use:
  → Kill process: lsof -ti:8000 | xargs kill -9
  → Restart server
